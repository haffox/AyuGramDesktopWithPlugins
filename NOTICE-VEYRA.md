# Veyra — source and attribution

Veyra is an independent modified version of AyuGram Desktop, based on Telegram Desktop.
It is not an official AyuGram or Telegram release and is not endorsed by their authors.

- Veyra corresponding source: https://github.com/haffox/AyuGramDesktopWithPlugins
- AyuGram upstream: https://github.com/AyuGram/AyuGramDesktop
- Telegram Desktop upstream: https://github.com/telegramdesktop/tdesktop

Original copyright notices, LICENSE (GNU GPL v3) and LEGAL are retained.
Changes in this fork include the CPython plugin host, native message hooks, Windows
packaging and Veyra branding. Consult the matching release commit for source and build scripts.
CPython and other dependencies retain their own licenses; Python's license is included
in its runtime directory. Internal Ayu namespaces, SDK module names and data formats
remain unchanged for compatibility. Existing upstream artwork remains attributed to
its original authors; this rename does not introduce a new logo or claim ownership.
