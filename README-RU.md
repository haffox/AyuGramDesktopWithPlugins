# Veyra Desktop

Независимый клиент на базе AyuGram Desktop и Telegram Desktop с Python-плагинами.

- [Сборка Windows](https://github.com/haffox/AyuGramDesktopWithPlugins/actions/workflows/build.yml)
- [Установщик и portable](https://github.com/haffox/AyuGramDesktopWithPlugins/releases)
- [Инструкции сборки и ограничения плагинов](docs/PLUGINS.md)
- [Авторы исходников и лицензии](NOTICE-VEYRA.md)

Приложение: `Veyra.exe`. Установщик: `Veyra-<версия>-windows-x64-setup.exe`.
Готовая сборка подтверждается только успешным Actions и наличием артефактов.
Установщик без цифровой подписи; плагины исполняют доверенный код без песочницы.
Совместимость с ExteraGram частичная, без Android/Xposed.

Проект распространяется под GNU GPL v3: [LICENSE](LICENSE), [LEGAL](LEGAL).
Авторские уведомления AyuGram и Telegram Desktop сохранены. Это независимый форк,
а не официальный релиз исходных проектов. Иконки пока остаются прежними.
URL репозитория и идентификаторы SDK сохранены для совместимости.
Существующий профиль AyuGram автоматически не переносится и не удаляется.
