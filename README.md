# AyuGram Desktop With Plugins

Repository initialization for importing the complete AyuGram Desktop source tree at `0f2a31bb420de98f331990432265b131b8d836b5` and applying the native CPython plugin integration.

The source import workflow preserves the pinned upstream submodules. After import, the Windows workflow builds the modified client and packages an unsigned installer. A successful build is not claimed until the Windows job completes.
